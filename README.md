# Countries Wiki

- Project for view countries details (flags, names, borders, area...) with [REST Countries API](https://restcountries.com)

- In project used:
  - UI:
    - ShadCN UI
    - motion (animation library)
    - Tailwind
  - Base:
    - Typescript
    - Redux (RTK + RKT Query)
    - React
    - React Router
  - Testing:
    - MSW
    - Testing Library
    - Vitest
  - Other:
    - FSD
    - Vite
